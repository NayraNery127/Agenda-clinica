# 12. Referências Bibliográficas

Fontes técnicas e documentação oficial consultadas durante o desenvolvimento.

- Nager.Date — API pública de feriados nacionais.
  [date.nager.at](https://date.nager.at)
- Prisma — documentação oficial do ORM utilizado na camada de persistência.
  [prisma.io/docs](https://www.prisma.io/docs)
- Express — documentação oficial do framework do backend.
  [expressjs.com](https://expressjs.com)
- React — documentação oficial da biblioteca do frontend.
  [react.dev](https://react.dev)
- Tailwind CSS — documentação oficial do framework de estilização.
  [tailwindcss.com/docs](https://tailwindcss.com/docs)
- Docker Compose — documentação oficial de orquestração de containers.
  [docs.docker.com/compose](https://docs.docker.com/compose)
- Docsify — documentação oficial do motor usado para publicar este site.
  [docsify.js.org](https://docsify.js.org)
- MDN Web Docs — referência sobre `Date`, fuso horário e a Fetch API.
  [developer.mozilla.org](https://developer.mozilla.org)
